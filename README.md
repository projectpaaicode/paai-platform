# PAAI Platform

Multi-tenant AI receptionist platform for local service businesses (auto repair, HVAC, salons, spas, pet groomers, dentists, chiropractors).  
Website + AI personal assistant + demo assets in a single monorepo.

## Vision

- Help local businesses **never miss a customer again**
- Provide a **24/7 AI receptionist** across website, social, SMS, and more
- Make onboarding so simple that a business owner can set up their AI in minutes

## Repository Structure

- `apps/marketing-site/` – Public-facing marketing website (landing pages, pricing, demo pages)
- `services/ai-assistant-api/` – Backend for AI chat, business configs, and multi-tenant logic
- `media/demo-video/` – Scripts, storyboard, and assets for faceless demo videos
- `docs/` – Architecture, product docs, and onboarding flows
- `.github/` – Issue templates, PR template, workflows
